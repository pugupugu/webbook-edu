CHAPTER5

관리자 화면(대시보드) 둘러보기

이 장에서 배울 것
  • 관리자 화면에 로그인할 수 있다.
  • 관리자 화면의 세 영역이 각각 무슨 역할을 하는지 안다.
  • 자주 쓰는 메뉴 네 가지를 찾아갈 수 있다.

5.1로그인하고 첫 화면 보기

워드프레스 관리자 화면은 언제나 같은 주소로 들어갑니다. 브라우저 주소창에 내사이트주소/wp-admin을 입력하고 관리자 아이디와 비밀번호로 로그인하세요. 자주 쓰게 되니 브라우저 즐겨찾기에 추가해 두면 편합니다.

로그인하면 가장 먼저 알림판이 보입니다. 영어로는 대시보드(Dashboard)라고 부르며, 사이트의 상태를 한눈에 보여 주는 첫 화면입니다.

5.2화면은 세 부분으로 나뉩니다

관리자 화면은 메뉴가 많아 보여도 구조는 단순합니다. 위쪽 막대, 왼쪽 메뉴, 가운데 작업 영역 세 부분뿐입니다.

상단 도구 막대는 어느 화면에 있든 항상 위에 붙어 있습니다. 왼쪽의 사이트 이름을 누르면 방문자가 보는 실제 사이트로 이동하고, + 새로 추가로 글이나 페이지를 바로 만들 수 있습니다. 오른쪽 끝에는 내 계정 메뉴와 로그아웃이 있습니다.

왼쪽 메뉴에는 워드프레스의 모든 기능이 모여 있습니다. 메뉴 위에 마우스를 올리면 하위 메뉴가 펼쳐집니다. 플러그인을 설치하면 이곳에 새 메뉴가 생기기도 합니다.

작업 영역은 실제로 일을 하는 곳입니다. 왼쪽 메뉴에서 무엇을 골랐느냐에 따라 글 목록, 설정 화면, 플러그인 목록 등으로 바뀝니다.

5.3꼭 알아야 할 메뉴는 네 개

왼쪽 메뉴는 열 개가 넘지만 처음에는 네 개만 알면 됩니다.

메뉴 하는 일 배우는 곳
글 블로그 글 쓰기, 카테고리 관리 7~8장
페이지 소개·문의 같은 고정 페이지 만들기 7~8장
외모 테마 바꾸기, 사이트 모양 꾸미기 10~11장
설정 사이트 이름, 주소 형식 등 기본 설정 6장

나머지 메뉴는 필요할 때 쓰면 됩니다. 미디어는 올린 사진을 모아 보는 곳(9장), 플러그인은 기능을 더하는 곳(12장), 사용자는 함께 관리할 사람을 추가하는 곳(15장)입니다. 댓글과 도구는 자주 쓰지 않습니다.

팁

관리자 화면에서 길을 잃으면 왼쪽 메뉴 맨 위의 알림판을 누르세요. 언제든 첫 화면으로 돌아갑니다.

5.4사이트 보기와 관리자 화면 오가기

워드프레스는 두 개의 얼굴을 가지고 있습니다. 내가 관리하는 관리자 화면과 방문자가 보는 사이트 화면입니다. 무언가를 바꾸면 사이트 화면에서 어떻게 보이는지 확인하는 습관을 들이세요.

관리자 화면에서 상단 막대의 사이트 이름을 누르면 사이트 화면으로 갑니다. 로그인한 상태라면 사이트 화면 위에도 같은 검은 막대가 보이고, 거기서 다시 사이트 이름을 누르면 관리자 화면으로 돌아옵니다.

예를 들면6장에서 사이트 제목을 "에이포의 공부방"으로 바꿨다고 해 봅시다. 저장한 뒤 상단 막대의 사이트 이름을 눌러 사이트 화면으로 가 보면, 브라우저 탭과 사이트 맨 위에 새 제목이 보입니다. 이렇게 "바꾸고, 확인하고, 돌아오는" 흐름이 워드프레스 작업의 기본입니다.

방문자가 실제로 보는 모습을 정확히 확인하고 싶을 때는 브라우저의 시크릿 창(로그인하지 않은 상태)으로 사이트를 열어 보세요.

스스로 확인하기 — 5장을 마쳤다면

  • /wp-admin 주소로 로그인하고 즐겨찾기에 추가했다.
  • 상단 도구 막대, 왼쪽 메뉴, 작업 영역을 구분할 수 있다.
  • 글, 페이지, 외모, 설정 메뉴의 위치를 안다.
  • 관리자 화면과 사이트 화면을 오갈 수 있다.
