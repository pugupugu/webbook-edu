CHAPTER16

검색 노출과 속도 기초

이 장에서 배울 것
  • 검색 노출(SEO)의 기본 세 가지를 지킬 수 있다.
  • 구글 서치 콘솔과 네이버 서치어드바이저에 사이트를 등록할 수 있다.
  • 사이트 속도를 점검하고 쉬운 개선을 할 수 있다.

16.1SEO, 기본 세 가지만

SEO(검색 엔진 최적화)는 내 사이트가 검색 결과에 잘 나오도록 다듬는 일입니다. 깊이 들어가면 끝이 없지만, 처음에는 아래 세 가지만 지켜도 충분합니다.

첫째, 제목을 구체적으로 씁니다. 검색하는 사람이 쓸 만한 말을 제목에 넣으세요. "오늘의 일기"보다 "제주 협재 해변 가족 여행 코스"가 검색에 훨씬 잘 걸립니다.

둘째, 설명을 따로 씁니다. 검색 결과에서 제목 아래 보이는 두 줄이 설명(메타 설명)입니다. 13장에서 설치한 SEO 플러그인이 글쓰기 화면 아래에 입력 칸을 만들어 줍니다. 글 내용을 한두 문장으로 요약해 넣으면, 검색 결과에서 클릭할 마음이 드는 소개가 됩니다.

셋째, 주소를 깔끔하게 둡니다. 6장에서 고유주소를 "글 이름"으로 바꾸고, 7장에서 슬러그를 짧은 영어로 정리한 것이 바로 이 작업입니다.

여기에 8장의 제목 단계(H2, H3)와 9장의 대체 텍스트까지 지켰다면, 기본적인 SEO는 이미 갖춘 셈입니다. 결국 가장 좋은 SEO는 찾는 사람에게 도움이 되는 글을 꾸준히 쓰는 것입니다.

16.2검색 엔진에 내 사이트 알리기

검색 엔진은 시간이 지나면 새 사이트를 스스로 찾아내지만, 직접 알려 주면 훨씬 빨리 수집합니다. 국내 방문자를 생각하면 구글과 네이버 두 곳에 등록해 두는 것이 일반적입니다.

시작하기 전에 6.3절의 검색 엔진 가시성 체크가 해제되어 있는지 다시 확인하세요. 체크되어 있으면 등록해도 수집되지 않습니다.

구글 서치 콘솔

  1. search.google.com/search-console 에 구글 계정으로 접속합니다.
  2. URL 접두어 방식으로 내 사이트 주소(https:// 포함)를 입력합니다.
  3. 소유권 확인 방법 중 HTML 태그를 고르고, 나오는 코드를 복사합니다.
  4. SEO 플러그인 설정의 "사이트 인증" 또는 "웹마스터 도구" 칸에 코드를 붙여 넣고 저장한 뒤, 서치 콘솔에서 확인을 누릅니다.
  5. 왼쪽 메뉴의 Sitemaps에 SEO 플러그인이 만든 사이트맵 주소를 제출합니다. 보통 내사이트주소/sitemap_index.xml 형태이며, 정확한 주소는 SEO 플러그인 설정에서 확인할 수 있습니다.

네이버 서치어드바이저

  1. searchadvisor.naver.com 에 네이버 계정으로 접속해 웹마스터 도구로 들어갑니다.
  2. 사이트 주소를 등록하고, HTML 태그 방식으로 소유 확인 코드를 받습니다.
  3. 구글과 같은 방법으로 SEO 플러그인에 코드를 넣고 확인합니다. SEO 플러그인에 네이버 칸이 없다면 헤더에 코드를 넣어 주는 작은 플러그인을 쓰면 됩니다.
  4. 요청 → 사이트맵 제출에서 사이트맵 주소를 제출합니다.

16.3사이트 속도 점검과 개선

사이트가 느리면 방문자는 기다려 주지 않고 떠납니다. 검색 순위에도 영향을 줍니다. 속도는 구글의 무료 도구인 PageSpeed Insights(pagespeed.web.dev)에서 확인할 수 있습니다. 주소를 넣으면 모바일과 데스크톱 점수, 그리고 개선할 점을 알려 줍니다.

점수가 낮게 나왔다면 대부분 아래 네 가지로 좋아집니다.

  1. 사진 크기를 줄입니다. 가장 효과가 큽니다. 9장의 방법대로 이미 올린 큰 사진도 줄여서 다시 올리세요.
  2. 캐시를 켭니다. 13장의 캐시 플러그인이나 호스팅의 캐시 기능을 씁니다.
  3. 플러그인을 줄입니다. 쓰지 않는 플러그인을 지웁니다.
  4. 가벼운 테마를 씁니다. 기본 테마처럼 단순한 블록 테마는 대체로 빠릅니다.
팁

점수 100점을 목표로 할 필요는 없습니다. 점수에 매달리기보다 스마트폰으로 내 사이트를 직접 열어 보고, 답답하지 않게 열리는지를 기준으로 삼으세요.

스스로 확인하기 — 16장을 마쳤다면

  • 글 제목을 검색할 만한 말로 쓰고, 메타 설명을 입력했다.
  • 검색 엔진 가시성 체크가 해제되어 있다.
  • 구글 서치 콘솔에 사이트를 등록하고 사이트맵을 제출했다.
  • 네이버 서치어드바이저에 사이트를 등록하고 사이트맵을 제출했다.
  • PageSpeed Insights로 속도를 확인했다.
