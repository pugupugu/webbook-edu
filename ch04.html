CHAPTER4

카페24로 쉽게 설치하기

이 장에서 배울 것
  • 카페24 워드프레스 호스팅을 신청할 수 있다.
  • 자동 설치된 워드프레스 관리자 화면에 들어갈 수 있다.
  • 내 도메인을 연결하고 SSL(https)을 적용할 수 있다.

4.1카페24 워드프레스 호스팅 이해하기

카페24는 국내에서 많이 쓰는 호스팅 업체입니다. 워드프레스 전용 호스팅 상품을 신청하면 3장에서 직접 했던 서버 준비, 데이터베이스 만들기, 파일 올리기, 설치 마법사를 카페24가 모두 대신 처리합니다.

워드프레스 호스팅 상품은 크게 두 종류로 나뉩니다. 일반 워드프레스 호스팅은 저렴하고, 업데이트와 백업 같은 관리를 내가 직접 합니다. 매니지드 워드프레스 호스팅은 가격이 더 높은 대신 속도 최적화나 보안 같은 관리를 업체가 더 많이 맡아 줍니다. 상품 이름과 구성, 가격은 자주 바뀌므로 신청하기 전에 카페24 호스팅 페이지에서 지금 판매 중인 상품을 비교해 보세요.

처음이라면 일반 워드프레스 호스팅의 가장 기본 상품으로 시작해도 충분합니다. 이 웹북의 6부에서 업데이트, 백업, 보안을 직접 관리하는 법을 배우기 때문입니다.

  • 준비 방법: 카페24 호스팅 사이트에서 워드프레스 호스팅 메뉴 캡처

4.2회원가입과 호스팅 신청

  1. 카페24 호스팅 사이트(hosting.cafe24.com)에 접속해 회원가입을 합니다.
  2. 상단 메뉴에서 워드프레스 호스팅을 고릅니다.
  3. 원하는 상품의 신청하기를 누릅니다.
  4. 호스팅 아이디를 정합니다. 이 아이디는 임시 주소와 FTP 아이디로도 쓰이니 신중하게 정하세요.
  5. 결제 기간을 고르고 결제합니다.

신청 과정에서 워드프레스 관리자 아이디와 비밀번호를 정하는 화면이 나옵니다. 이 정보는 사이트에 로그인할 때 쓰니 반드시 메모해 두세요.

4.3자동 설치 확인과 관리자 접속

결제가 끝나면 보통 몇 분 안에 워드프레스 설치가 완료됩니다. 카페24는 도메인을 연결하기 전에도 접속할 수 있는 임시 주소를 줍니다. 일반적으로 호스팅아이디.mycafe24.com 같은 형태이며, 정확한 주소는 나의 서비스 관리 화면에서 확인할 수 있습니다.

  1. 카페24에 로그인하고 나의 서비스 관리로 들어갑니다.
  2. 신청한 호스팅의 기본 정보에서 임시 주소(기본 도메인)를 확인합니다.
  3. 브라우저에 임시주소/wp-admin을 입력합니다.
  4. 신청할 때 정한 워드프레스 관리자 아이디와 비밀번호로 로그인합니다.

관리자 화면이 보이면 설치는 끝났습니다. 3장의 다섯 단계를 카페24가 대신 해 준 것입니다.

4.4도메인 연결하기

임시 주소로도 사이트는 열리지만, 실제로 공개하려면 내 도메인을 연결해야 합니다. 도메인을 어디서 샀는지에 따라 방법이 조금 다릅니다.

카페24에서 도메인을 산 경우에는 나의 서비스 관리의 도메인 연결 메뉴에서 보유한 도메인을 골라 호스팅에 연결하면 끝납니다.

다른 업체에서 도메인을 산 경우에는 두 곳에서 작업해야 합니다. 먼저 카페24 호스팅 관리 화면에 그 도메인을 등록합니다. 다음으로 도메인을 산 업체의 관리 화면에 들어가서, 네임서버를 카페24가 안내하는 값으로 바꿉니다.

용어네임서버

도메인이 어느 호스팅(땅)을 가리킬지 정해 주는 안내소입니다. 네임서버를 카페24로 바꾸면 "이 주소로 오는 사람은 카페24에 있는 내 집으로 보내라"고 알려 주는 셈입니다.

주의

도메인 연결이나 네임서버를 바꾼 뒤 실제로 적용되기까지 짧게는 몇 분, 길게는 하루 정도 걸립니다. 바로 안 열린다고 여러 번 바꾸지 말고 기다려 보세요.

마지막으로 워드프레스 관리자 화면의 설정 → 일반에서 "워드프레스 주소"와 "사이트 주소"가 내 도메인으로 바뀌었는지 확인합니다. 카페24 도메인 연결 과정에서 자동으로 바뀌는 경우가 많지만, 임시 주소로 남아 있다면 두 칸을 모두 내 도메인으로 고칩니다.

4.5SSL(https) 적용하기

SSL은 방문자와 사이트 사이에 오가는 정보를 암호화하는 보안 인증서입니다. SSL을 적용하면 주소가 http://에서 https://로 바뀌고, 브라우저 주소창의 "안전하지 않음" 경고가 사라집니다. 요즘은 SSL이 없으면 방문자가 불안해하고 검색 결과에서도 불리하므로 꼭 적용해야 합니다.

  1. 카페24 나의 서비스 관리에서 보안서버(SSL) 메뉴로 들어갑니다.
  2. 연결한 도메인에 SSL 인증서를 신청합니다. 카페24는 무료 인증서를 제공하는 경우가 많으니 먼저 확인하세요.
  3. 적용이 끝나면 워드프레스의 설정 → 일반에서 두 주소를 https://로 시작하도록 고칩니다.
  4. 브라우저에서 https://내도메인으로 접속해 자물쇠 아이콘이 보이는지 확인합니다.

스스로 확인하기 — 4장을 마쳤다면

  • 카페24 워드프레스 호스팅을 신청하고 관리자 정보를 메모했다.
  • 임시 주소로 관리자 화면에 로그인했다.
  • 내 도메인을 연결했고, 설정의 두 주소가 내 도메인으로 되어 있다.
  • https://내도메인으로 접속하면 자물쇠 표시가 보인다.
