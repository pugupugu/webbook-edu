CHAPTER3

직접 설치하기 — 워드프레스 다운로드부터

이 장에서 배울 것
  • wordpress.org에서 워드프레스를 내려받을 수 있다.
  • 데이터베이스를 만들고 그 정보를 설치에 쓸 수 있다.
  • FTP로 파일을 올리고 설치 마법사로 설치를 마칠 수 있다.
  • 연습용으로 내 PC에 워드프레스를 설치할 수 있다.

3.1전체 흐름 먼저 보기

직접 설치는 다섯 단계로 끝납니다. 처음엔 낯설지만 한 번 해 보면 30분이면 충분합니다. 이 장은 호스팅(땅)을 이미 빌렸다는 전제로 진행합니다. 호스팅에는 FTP 접속 정보와 데이터베이스를 만들 수 있는 관리 화면이 있어야 합니다.

시작하기 전에 0장에서 준비한 메모장을 열어 두세요. 이 장에서 나오는 정보를 하나씩 적어 나갑니다.

3.2워드프레스 내려받기

워드프레스 프로그램은 공식 사이트에서 무료로 받을 수 있습니다.

  1. 브라우저에서 ko.wordpress.org 에 접속합니다. 한국어판 공식 사이트입니다.
  2. 화면의 워드프레스 받기 버튼을 누릅니다.
  3. 최신 버전의 zip 파일을 내려받습니다.
  4. 내려받은 zip 파일의 압축을 풉니다. wordpress라는 폴더가 생깁니다.

  • 준비 방법: ko.wordpress.org/download 접속 후 캡처

주의

워드프레스는 반드시 공식 사이트에서 받으세요. 다른 곳에서 받은 파일에는 악성 코드가 섞여 있을 수 있습니다.

3.3서버 조건 확인하기

워드프레스가 잘 돌아가려면 호스팅 서버가 몇 가지 조건을 갖춰야 합니다. 작성 시점의 공식 권장 사양은 PHP 8.3 이상, MySQL 8.0 이상 또는 MariaDB 10.6 이상, 그리고 HTTPS 지원입니다. 권장 사양은 버전이 올라가면서 바뀌므로 설치 전에 wordpress.org의 요구 사항(Requirements) 페이지에서 한 번 더 확인하세요.

용어가 어렵게 느껴져도 걱정하지 않아도 됩니다. PHP는 워드프레스가 쓰는 프로그래밍 언어이고, MySQL과 MariaDB는 데이터베이스 프로그램입니다. 요즘 대부분의 호스팅은 이 조건을 기본으로 갖추고 있으니, 호스팅 상품 설명에서 "PHP 8.x"와 "MySQL" 또는 "MariaDB"라는 글자만 확인하면 됩니다.

3.4데이터베이스 만들기

1장에서 데이터베이스는 글과 설정을 보관하는 창고라고 했습니다. 워드프레스를 설치하기 전에 이 창고를 먼저 만들어 두어야 합니다.

  1. 호스팅 관리 화면에 로그인합니다.
  2. 데이터베이스(DB) 또는 MySQL 메뉴를 찾습니다.
  3. 새 데이터베이스를 만들고, 그 데이터베이스를 쓸 사용자와 비밀번호를 정합니다.
  4. 아래 네 가지 정보를 메모장에 적습니다.
DB 이름:      (예: mysite_wp)
DB 사용자:    (예: mysite_user)
DB 비밀번호:  (직접 정한 비밀번호)
DB 호스트:    (대부분 localhost, 호스팅 안내문 확인)

호스팅마다 메뉴 이름과 위치가 조금씩 다릅니다. 메뉴를 찾기 어렵다면 호스팅 업체 도움말에서 "데이터베이스 만들기"를 검색하세요. 호스팅에 따라서는 가입할 때 데이터베이스가 자동으로 하나 만들어져 있기도 합니다.

3.5파일 올리기와 설치 마법사

FTP로 파일 올리기

FTP는 내 컴퓨터의 파일을 서버로 옮기는 통로입니다. 무료 프로그램인 파일질라(FileZilla)를 많이 씁니다.

용어FTP

File Transfer Protocol의 줄임말로, 파일을 서버에 올리고 내려받는 방법입니다. 내 PC와 서버 사이의 택배 통로라고 생각하면 됩니다.

  1. filezilla-project.org에서 파일질라 클라이언트를 내려받아 설치합니다.
  2. 파일질라 위쪽 칸에 호스팅에서 받은 FTP 정보(호스트, 사용자명, 비밀번호, 포트)를 입력하고 빠른 연결을 누릅니다.
  3. 왼쪽 창은 내 컴퓨터, 오른쪽 창은 서버입니다. 오른쪽에서 웹사이트 폴더(보통 www 또는 public_html)를 엽니다.
  4. 왼쪽에서 압축을 푼 wordpress 폴더 안의 파일 전체를 선택해 오른쪽으로 끌어다 놓습니다.
  5. 전송이 끝날 때까지 기다립니다. 파일이 많아서 몇 분 걸립니다.
주의

wordpress 폴더 자체를 올리면 사이트 주소가 mysite.com/wordpress가 됩니다. 폴더를 열고 그 안의 내용물을 올려야 mysite.com에서 바로 열립니다.

설치 마법사 실행하기

파일을 다 올렸으면 브라우저에서 내 사이트 주소에 접속합니다. 워드프레스가 알아서 설치 마법사를 띄워 줍니다.

  1. 언어로 한국어를 고르고 계속합니다.
  2. 3.4절에서 메모한 DB 이름, 사용자, 비밀번호, 호스트를 입력합니다. 테이블 접두어는 그대로 둡니다.
  3. 설치 실행하기를 누릅니다.
  4. 사이트 제목, 관리자 사용자명, 비밀번호, 이메일을 입력합니다.
  5. 워드프레스 설치를 누르면 끝입니다.

관리자 사용자명은 admin처럼 누구나 짐작할 수 있는 이름을 피하세요. 해킹 시도가 가장 먼저 노리는 이름입니다. 비밀번호는 워드프레스가 제안하는 강한 비밀번호를 그대로 쓰고 메모해 두면 됩니다.

그림 자리 IMG-3-4 | 캡처
  • 내용: 설치 마법사 두 화면 — ① DB 정보 입력 화면 ② 사이트 제목·관리자 계정 입력 화면
  • 준비 방법: 설치 진행 중 각 화면 캡처, 두 장을 나란히 배치

설치가 끝나면 로그인 화면이 나옵니다. 앞으로 관리자 화면에 들어갈 때는 내사이트주소/wp-admin 으로 접속합니다.

3.6내 PC에 연습용으로 설치하기

인터넷에 공개하지 않고 연습만 하고 싶다면 내 컴퓨터에 설치하는 방법이 가장 간단합니다. 서버, FTP, 데이터베이스를 따로 준비하지 않아도 됩니다. 이런 일을 대신해 주는 무료 프로그램이 있기 때문입니다. 대표적인 것이 Local(localwp.com)입니다.

  1. localwp.com에서 Local을 내려받아 설치합니다.
  2. Local을 실행하고 + 버튼(새 사이트 만들기)을 누릅니다.
  3. 사이트 이름을 입력하고, 환경은 Preferred(권장)를 고릅니다.
  4. 관리자 사용자명과 비밀번호를 정합니다.
  5. 잠시 기다리면 사이트가 만들어집니다. WP Admin 버튼을 누르면 관리자 화면이 열립니다.
그림 자리 IMG-3-5 | 캡처
  • 내용: Local 프로그램에서 사이트를 만든 뒤의 화면. "WP Admin", "Open site" 버튼 표시
  • 준비 방법: Local 설치 후 연습 사이트를 만들어 캡처
  • 파일명: img-3-5_Local-사이트.png

내 PC에 만든 사이트는 그 컴퓨터에서만 열립니다. 연습이 끝나고 실제로 공개하고 싶어지면 3.2~3.5절이나 4장 방식으로 다시 설치하면 됩니다.

스스로 확인하기 — 3장을 마쳤다면

  • 공식 사이트에서 워드프레스를 내려받았다.
  • 데이터베이스 정보 네 가지를 메모해 두었다.
  • 워드프레스 폴더 안의 파일을 서버의 웹사이트 폴더에 올렸다.
  • 설치 마법사를 마치고 /wp-admin으로 로그인했다.
  • (연습용) 내 PC에 Local로 사이트를 만들어 보았다.

다음 장에서는 카페24로 훨씬 간단하게 설치하는 방법을 알아봅니다. 직접 설치를 마친 분도 4.4절(도메인 연결)과 4.5절(SSL)은 꼭 읽어 주세요.
