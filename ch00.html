CHAPTER0

이 웹북 사용법

이 장에서 배울 것
  • 이 웹북이 어떤 방식으로 가르치는지 알 수 있다.
  • 실습을 시작하기 전에 무엇을 준비해야 하는지 알 수 있다.

0.1"다 배우려 하지 마세요"

워드프레스는 기능이 아주 많습니다. 메뉴만 수십 개이고, 설치해서 쓸 수 있는 플러그인(기능 추가 프로그램)은 수만 개가 넘습니다. 처음 시작하는 사람이 이걸 다 배우려고 하면 금방 지칩니다.

그런데 실제로 사이트를 만들고 운영하는 데 매일 쓰는 기능은 생각보다 적습니다. 일반적으로 개인 블로그나 작은 회사 홈페이지라면 전체 기능의 20% 정도만 알아도 충분히 운영할 수 있습니다.

이 웹북은 바로 그 20%만 다룹니다.

이 웹북에서 하는 것 이 웹북에서 하지 않는 것
설치부터 사이트 1개 완성까지 모든 메뉴와 버튼 설명
꼭 필요한 설정만 코딩(HTML, PHP 등)
자주 쓰는 블록 10개 쇼핑몰, 회원제 같은 고급 기능 (개념만 소개)
꼭 필요한 플러그인만 플러그인 수십 개 비교

예를 들면자동차를 운전하려고 엔진 구조까지 공부하지는 않습니다. 시동 걸기, 기어 바꾸기, 브레이크 밟기를 알면 운전할 수 있습니다. 워드프레스도 똑같습니다. "운전에 필요한 것"만 먼저 배우고, 더 필요해지면 그때 하나씩 더 배우면 됩니다.

0.2전체 학습 흐름

이 웹북은 7개 부(部)로 되어 있습니다. 순서대로 따라가면 마지막 장에서 내 사이트 하나가 완성됩니다.

부 무엇을 배우나 끝나면 할 수 있는 것
0부 워드프레스 기본 개념 도메인, 호스팅, 워드프레스가 무엇인지 설명할 수 있다
1부 설치 내 워드프레스 사이트가 인터넷에 열린다
2부 관리자 화면과 필수 설정 처음 해야 할 설정을 끝낸다
3부 글, 페이지, 이미지 글과 페이지를 직접 만든다
4부 테마와 사이트 편집기 사이트 모양을 원하는 대로 바꾼다
5부 플러그인 문의 폼, 백업 같은 기능을 더한다
6부 운영과 관리 업데이트, 백업, 보안을 스스로 관리한다
7부 마무리 실습 사이트를 완성하고 공개한다
팁

1부(설치)는 처음 해 보는 사람에게 가장 어려운 부분입니다. 여기만 넘기면 나머지는 대부분 "클릭해서 바꿔 보는" 작업이라 훨씬 쉽습니다.

0.3각 장은 이렇게 구성됩니다

모든 장은 같은 순서로 진행합니다. 순서가 같으면 지금 어디쯤 와 있는지 바로 알 수 있습니다.

단계 내용 웹북에서 보이는 모양
1. 목표 이 장을 마치면 할 수 있게 되는 것 장 맨 위의 "이 장의 목표" 상자
2. 개념 꼭 필요한 만큼만, 비유로 설명 본문과 그림
3. 따라하기 화면을 보며 한 단계씩 실습 번호가 붙은 단계와 화면 캡처
4. 체크 제대로 됐는지 스스로 확인 장 맨 끝의 체크리스트

웹북 곳곳에 아래와 같은 상자가 나옵니다.

상자 의미
팁 알아 두면 편한 요령
주의 놓치면 문제가 생기는 부분
용어 처음 나오는 낱말 풀이

실습을 시작하기 전에 아래를 준비해 주세요.

준비물 왜 필요한가 필수 여부
컴퓨터 (윈도우 또는 맥) 모든 실습은 컴퓨터 브라우저로 합니다. 스마트폰으로는 실습이 어렵습니다. 필수
인터넷 브라우저 (크롬 권장) 워드프레스 관리 화면을 여는 데 씁니다. 필수

결제 수단 카페24 같은 유료 호스팅을 쓸 때 필요합니다. 4장 카페24 실습 시
메모장 아이디, 비밀번호, 데이터베이스 정보처럼 설치 중 나오는 정보를 적어 둡니다. 강력 추천
