CHAPTER13

꼭 필요한 플러그인만

이 장에서 배울 것
  • 대부분의 사이트에 필요한 플러그인 여섯 가지 용도를 안다.
  • 용도별로 플러그인 하나씩을 골라 설치할 수 있다.
  • 같은 용도의 플러그인을 겹쳐 설치하지 않는다.

13.1용도별로 하나씩이면 충분합니다

작은 사이트에 필요한 플러그인은 대개 여섯 가지 용도로 정리됩니다. 보안, 백업, 검색 노출(SEO), 문의 폼, 속도(캐시), 스팸 방지입니다. 용도마다 하나씩만 고르면 됩니다.

아래 표는 공식 저장소에서 오랫동안 많이 쓰여 온 무료 플러그인입니다. 이 웹북이 추천하는 것은 특정 제품이 아니라 "용도마다 하나"라는 원칙이므로, 12장의 기준으로 확인해 보고 다른 플러그인을 골라도 괜찮습니다. 플러그인 이름과 기능은 업데이트로 바뀔 수 있습니다.

용도 대표 플러그인 (무료) 하는 일
보안 Wordfence Security 로그인 공격 차단, 악성 코드 검사
백업 UpdraftPlus 사이트 전체를 정해진 주기로 자동 백업
검색 노출 Yoast SEO 또는 Rank Math 검색 결과 제목·설명 관리, 사이트맵 생성
문의 폼 Contact Form 7 또는 WPForms Lite 문의하기 양식 만들기
속도 WP Super Cache 등 캐시 플러그인 페이지를 미리 만들어 두어 빠르게 보여 줌
스팸 방지 Akismet 또는 Antispam Bee 스팸 댓글·문의 자동 차단

13.2용도별로 알아 둘 점

보안. 보안 플러그인은 로그인 화면에 비밀번호를 수없이 넣어 보는 공격을 막고, 수상한 파일이 생기면 알려 줍니다. 설치 후 기본 설정만으로도 효과가 있습니다. 15장의 보안 수칙과 함께 쓰세요.

백업. 백업 플러그인은 반드시 설치해야 하는 플러그인입니다. 백업 파일은 서버 안이 아니라 구글 드라이브나 드롭박스 같은 외부 저장소에 보관되도록 설정하세요. 서버에 문제가 생기면 서버 안의 백업도 함께 사라지기 때문입니다. 설정과 복원 방법은 14장에서 실습합니다.

검색 노출. SEO 플러그인은 글마다 검색 결과에 보일 제목과 설명을 따로 정할 수 있게 해 주고, 검색 엔진에 제출할 사이트맵을 자동으로 만들어 줍니다. 16장에서 이 사이트맵을 쓰게 됩니다. SEO 플러그인은 두 개를 함께 쓰면 서로 충돌하니 하나만 고르세요.

문의 폼. 방문자가 이름, 이메일, 내용을 입력해 보내면 내 이메일로 전달됩니다. 설치 후 만들어지는 짧은 코드(숏코드)나 전용 블록을 "문의" 페이지에 넣으면 됩니다. 폼을 만든 뒤에는 직접 한 번 보내 보고 메일이 잘 오는지 꼭 확인하세요.

속도. 캐시 플러그인은 자주 보는 페이지를 미리 만들어 두었다가 바로 보여 줘서 사이트를 빠르게 합니다. 다만 호스팅에 따라 서버 자체에서 캐시를 제공하는 경우가 있습니다. 예를 들어 LiteSpeed 서버를 쓰는 호스팅은 LiteSpeed Cache 플러그인이 가장 잘 맞습니다. 호스팅 안내를 먼저 확인하고, 캐시 플러그인도 하나만 쓰세요.

스팸 방지. 댓글이나 문의 폼을 열어 두면 광고성 스팸이 반드시 들어옵니다. Akismet은 워드프레스를 만든 회사의 서비스로 정확도가 높지만, 개인 사이트가 아닌 상업용 사이트는 유료 요금제가 필요할 수 있습니다. 무료로 쓰고 싶다면 Antispam Bee 같은 대안이 있습니다.

13.3겹치지 않게, 하나씩 확인하며

플러그인을 설치할 때는 한 번에 여러 개를 깔지 말고 하나씩 설치하세요. 하나를 설치하고 활성화한 뒤 사이트가 잘 보이는지 확인하고, 다음 것을 설치합니다. 문제가 생겨도 방금 설치한 것이 원인이라는 것을 바로 알 수 있습니다.

같은 용도의 플러그인을 두 개 쓰는 것도 피하세요. 보안 플러그인 두 개, 캐시 플러그인 두 개를 함께 쓰면 서로 같은 일을 하려다 부딪혀 오류가 나거나 사이트가 오히려 느려집니다.

예를 들면카페24 매니지드 호스팅처럼 호스팅이 보안과 캐시를 이미 제공하는 경우, 보안·캐시 플러그인을 또 설치하면 기능이 겹칩니다. 이럴 때는 호스팅의 안내를 따르고 백업, SEO, 문의 폼처럼 호스팅이 대신해 주지 않는 용도만 플러그인으로 채우면 됩니다.

스스로 확인하기 — 13장을 마쳤다면

  • 여섯 가지 용도(보안, 백업, SEO, 문의 폼, 속도, 스팸 방지)를 안다.
  • 백업 플러그인을 설치하고 외부 저장소를 연결했다.
  • SEO 플러그인을 하나만 설치했다.
  • 문의 폼을 만들어 직접 보내 보고 메일이 오는지 확인했다.
  • 같은 용도의 플러그인이 두 개 설치되어 있지 않다.

5부를 마쳤습니다. 다음 장부터는 사이트를 오래 안전하게 운영하는 법을 배웁니다.
