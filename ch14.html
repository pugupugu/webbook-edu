CHAPTER14

업데이트와 백업

이 장에서 배울 것
  • 업데이트 세 종류를 구분하고 안전한 순서로 진행할 수 있다.
  • 업데이트 전에 백업하는 습관을 들인다.
  • 백업 파일로 사이트를 복원할 수 있다.

14.1업데이트는 세 종류

워드프레스 사이트에서 업데이트할 대상은 세 가지입니다. 워드프레스 본체(코어), 테마, 플러그인입니다. 업데이트에는 새 기능도 들어 있지만, 가장 중요한 것은 보안 구멍을 메우는 수정입니다. 업데이트를 미루면 이미 알려진 구멍을 그대로 열어 두는 셈입니다.

업데이트할 것이 생기면 관리자 화면 왼쪽 메뉴의 알림판 → 업데이트 옆에 숫자가 표시됩니다. 이 화면에서 세 종류를 한 번에 볼 수 있습니다.

  • 준비 방법: 업데이트 대상이 있을 때 캡처 (없으면 오래된 버전의 플러그인을 설치해 연출)
  • 파일명: img-14-1_업데이트-화면.png

작은 보안 업데이트(예: 7.0.1 → 7.0.2)는 워드프레스가 자동으로 설치합니다. 큰 버전 업데이트(예: 7.0 → 7.1)와 플러그인·테마 업데이트는 내가 직접 하는 것이 기본입니다.

14.2안전한 업데이트 순서

업데이트는 대부분 아무 문제 없이 끝납니다. 하지만 아주 가끔 플러그인과 새 버전이 맞지 않아 화면이 깨지기도 합니다. 그래서 늘 같은 순서를 지키는 것이 좋습니다.

  1. 백업합니다. 문제가 생겼을 때 돌아갈 곳을 먼저 만들어 둡니다.
  2. 플러그인을 하나씩 업데이트합니다. 한꺼번에 하지 말고 하나 끝날 때마다 사이트를 확인하면 문제의 원인을 바로 찾을 수 있습니다.
  3. 테마를 업데이트합니다.
  4. 워드프레스 본체를 업데이트합니다.
  5. 사이트를 확인합니다. 첫 화면, 글 하나, 문의 폼 정도를 열어 보고 이상이 없는지 봅니다.
팁

업데이트는 방문자가 적은 시간에, 그리고 문제가 생겨도 대응할 시간이 있을 때 하세요. 퇴근 직전이나 중요한 행사 전날은 피하는 것이 좋습니다.

자동 업데이트를 켜 둘 수도 있습니다. 설치된 플러그인 목록에서 플러그인마다 자동 업데이트 활성화를 누르면 됩니다. 관리할 시간이 부족하다면 믿을 만한 플러그인 몇 개에만 켜 두고, 자동 백업과 함께 쓰는 것이 일반적인 방법입니다.

14.3백업과 복원 실습

13장에서 설치한 백업 플러그인(UpdraftPlus 기준)으로 실습합니다. 다른 백업 플러그인도 흐름은 비슷합니다.

자동 백업 설정하기

  1. 설정 → UpdraftPlus 백업으로 들어가 설정 탭을 엽니다.
  2. 파일 백업 주기와 데이터베이스 백업 주기를 정합니다. 글을 자주 쓰는 사이트라면 데이터베이스는 매일, 파일은 매주가 일반적입니다.
  3. 보관할 백업 개수를 정합니다. 너무 많으면 저장 공간을 차지하니 3~5개 정도면 충분합니다.
  4. 원격 저장소로 구글 드라이브 같은 외부 저장소를 고르고 안내에 따라 연결합니다.
  5. 변경 사항 저장을 누릅니다.

지금 바로 백업하기

업데이트 직전처럼 당장 백업이 필요할 때는 백업 / 복원 탭의 지금 백업 버튼을 누릅니다. 데이터베이스와 파일을 모두 포함하도록 체크하고 실행하면, 몇 분 안에 백업 목록에 새 항목이 생깁니다.

복원하기

  1. 백업 / 복원 탭의 기존 백업 목록에서 돌아가고 싶은 날짜를 찾습니다.
  2. 복원을 누르고 복원할 항목(플러그인, 테마, 업로드 파일, 데이터베이스 등)을 고릅니다. 무엇이 문제인지 모르겠다면 전부 고릅니다.
  3. 안내에 따라 진행하면 사이트가 그 시점으로 돌아갑니다.
주의

복원하면 백업 시점 이후에 쓴 글과 받은 댓글은 사라집니다. 복원하기 전에 지금 상태도 한 번 더 백업해 두면, 필요할 때 최근 내용을 다시 꺼내 볼 수 있습니다.

백업은 "만들어 두기"보다 "복원해 보기"가 더 중요합니다. 실제로 사고가 났을 때 처음 복원 버튼을 눌러 보는 것과, 미리 연습해 둔 것은 마음가짐부터 다릅니다. 연습용 글을 하나 지운 뒤 복원해서 되살려 보는 실습을 꼭 해 보세요.

스스로 확인하기 — 14장을 마쳤다면

  • 업데이트 세 종류(본체, 테마, 플러그인)를 구분할 수 있다.
  • 백업 → 플러그인 → 테마 → 본체 → 확인 순서를 안다.
  • 자동 백업 주기를 정하고 외부 저장소를 연결했다.
  • 연습용 글을 지웠다가 복원으로 되살려 보았다.
