CHAPTER6

처음 한 번만 하면 되는 필수 설정

이 장에서 배울 것
  • 사이트 제목, 언어, 시간대를 설정할 수 있다.
  • 고유주소를 알맞은 형식으로 바꿀 수 있다.
  • 첫 화면 표시 방식과 댓글 설정을 정할 수 있다.
  • 내 프로필과 비밀번호를 관리할 수 있다.

6.1일반 설정

왼쪽 메뉴에서 설정 → 일반으로 들어갑니다. 여기서 사이트의 이름표를 붙입니다.

사이트 제목은 브라우저 탭과 검색 결과에 표시되는 이름입니다. 태그라인은 사이트를 한 줄로 소개하는 문구인데, 비워 두거나 짧게 쓰는 것이 좋습니다. 기본으로 들어 있는 영어 문구가 있다면 지우세요.

사이트 언어는 한국어, 시간대는 서울로 맞춥니다. 시간대가 틀리면 예약 발행한 글이 엉뚱한 시간에 올라갑니다. 날짜 형식과 시간 형식은 마음에 드는 것을 고르면 됩니다.

모두 바꿨으면 화면 맨 아래 변경 사항 저장을 누르세요. 워드프레스의 설정 화면은 대부분 저장 버튼을 눌러야 반영됩니다.

6.2고유주소 — 가장 먼저 해야 하는 이유

고유주소는 글마다 붙는 인터넷 주소입니다. 영어로 퍼머링크(Permalink)라고 부릅니다. 기본 설정 그대로 두면 글 주소가 mysite.com/?p=123처럼 숫자로 만들어집니다. 이런 주소는 무슨 글인지 알 수 없고 검색 엔진에도 불리합니다.

설정 → 고유주소로 들어가서 글 이름을 고르고 저장하세요. 이제 글 주소가 mysite.com/wordpress-start처럼 글 내용을 담은 주소가 됩니다.

주의

고유주소는 글을 쓰기 시작하기 전에 정해야 합니다. 글이 쌓인 뒤에 바꾸면 이전 주소가 모두 바뀌어, 다른 곳에 공유해 둔 링크가 깨지고 검색 순위도 떨어질 수 있습니다.

팁

한글 제목으로 글을 쓰면 주소에도 한글이 들어갑니다. 주소를 공유할 때 글자가 %EC%9B...처럼 길게 깨져 보일 수 있으니, 글을 쓸 때 주소(슬러그)를 짧은 영어로 바꿔 주는 습관을 들이면 좋습니다. 방법은 7장에서 다룹니다.

6.3읽기 설정 — 첫 화면 정하기

설정 → 읽기에서는 방문자가 사이트에 처음 들어왔을 때 무엇을 보여 줄지 정합니다. 선택지는 두 가지입니다.

최신 글을 고르면 첫 화면에 가장 최근에 쓴 글 목록이 나옵니다. 블로그처럼 새 글이 중심인 사이트에 맞습니다.

정적인 페이지를 고르면 미리 만들어 둔 페이지 하나를 첫 화면으로 씁니다. 회사나 가게 홈페이지처럼 소개가 중심인 사이트에 맞습니다. 이때 "글 페이지"에 다른 페이지를 지정하면 블로그 글 목록은 그 페이지에서 따로 보여 줍니다.

예를 들면18장에서 만들 실습 사이트는 "홈" 페이지를 첫 화면으로, "블로그" 페이지를 글 목록으로 지정합니다. 첫 화면에서는 사이트를 소개하고, 소식은 블로그 메뉴에서 보는 구조입니다. 지금은 페이지가 없으니 기본값(최신 글)으로 두고, 7장에서 페이지를 만든 뒤 바꿔도 됩니다.

같은 화면 아래쪽의 검색 엔진 가시성에 체크되어 있으면 검색 엔진이 사이트를 수집하지 않습니다. 사이트를 공개할 준비가 되면 반드시 체크를 해제하세요. 16장에서 다시 확인합니다.

6.4토론(댓글) 설정

설정 → 토론은 댓글을 다루는 곳입니다. 처음에는 두 가지만 정하면 됩니다.

첫째, 댓글을 받을지 정합니다. 소개 위주의 사이트라면 "새 글에 대한 댓글 허용"의 체크를 해제해 댓글을 끄는 것이 관리하기 편합니다.

둘째, 댓글을 받는다면 댓글이 나타나기 전에 수동 승인 필요에 체크합니다. 내가 승인한 댓글만 보이므로 광고성 스팸 댓글이 바로 노출되지 않습니다. 스팸을 자동으로 거르는 방법은 13장에서 다룹니다.

6.5프로필과 비밀번호

사용자 → 프로필에서는 내 정보를 관리합니다. 꼭 바꿔 둘 것은 공개적으로 보일 이름입니다. 기본값은 로그인 아이디인데, 그대로 두면 글 작성자 이름으로 아이디가 노출됩니다. 성명이나 닉네임을 입력한 뒤 이 칸에서 그 이름을 고르세요.

비밀번호를 바꾸고 싶을 때도 이 화면 아래쪽의 새 비밀번호 설정을 쓰면 됩니다. 비밀번호 관리는 15장에서 더 자세히 다룹니다.

설정 위치 추천 값
설정 → 일반 사이트 언어 한국어, 시간대 서울
설정 → 고유주소 글 이름
설정 → 읽기 블로그형은 최신 글, 홈페이지형은 정적인 페이지
설정 → 토론 댓글 끄기, 또는 수동 승인
사용자 → 프로필 공개 이름을 아이디가 아닌 이름으로

스스로 확인하기 — 6장을 마쳤다면

  • 사이트 제목과 시간대를 설정하고 저장했다.
  • 고유주소를 "글 이름"으로 바꿨다.
  • 첫 화면 표시 방식을 정했다.
  • 댓글을 끄거나 수동 승인으로 바꿨다.
  • 공개 이름이 로그인 아이디와 다르게 보인다.

이제 사이트의 기본 틀이 갖춰졌습니다. 다음 장부터는 내용을 채워 나갑니다.
