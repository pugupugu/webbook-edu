CHAPTER8

블록 에디터, 이것만 알면 충분해

이 장에서 배울 것
  • 블록이 무엇인지 이해한다.
  • 자주 쓰는 블록 10개로 페이지를 만들 수 있다.
  • 블록을 옮기고, 복제하고, 지울 수 있다.
  • 패턴으로 완성된 디자인을 빠르게 넣을 수 있다.

8.1블록이라는 생각법

워드프레스의 글쓰기 화면을 블록 에디터라고 부릅니다. 이름처럼 모든 내용을 블록 단위로 다룹니다. 문단 하나가 블록 하나, 사진 한 장이 블록 하나, 버튼 하나가 블록 하나입니다. 페이지는 이런 블록을 위에서 아래로 쌓아 만듭니다.

블록 방식의 장점은 조립이 자유롭다는 것입니다. 순서를 바꾸고 싶으면 블록을 옮기면 되고, 필요 없으면 그 블록만 지우면 됩니다. 블록마다 따로 색이나 크기를 바꿀 수도 있습니다.

새 블록을 넣는 방법은 두 가지입니다. 화면의 + 버튼을 눌러 목록에서 고르거나, 빈 줄에서 슬래시(/)를 입력한 뒤 블록 이름을 치는 것입니다. 예를 들어 /이미지라고 치면 이미지 블록이 바로 나옵니다. 익숙해지면 슬래시 방식이 훨씬 빠릅니다.

  • 준비 방법: 새 페이지에서 두 상황을 각각 캡처해 나란히 배치
  • 파일명: img-8-1_블록-추가.png

8.2꼭 쓰는 블록 10개

블록 종류는 아주 많지만 대부분의 페이지는 아래 열 가지로 충분히 만들 수 있습니다.

블록 쓰임
문단 일반 글. 그냥 입력하면 자동으로 문단 블록이 됩니다.
제목 소제목. H2, H3처럼 크기(단계)를 고릅니다.
이미지 사진 한 장 넣기
목록 글머리 기호나 번호 목록
버튼 "문의하기"처럼 클릭을 유도하는 버튼
표 간단한 가격표, 일정표
인용 다른 사람의 말이나 강조할 문장
구분자 내용 사이를 나누는 가로선
열 화면을 2~3칸으로 나눠 나란히 배치
그룹 여러 블록을 묶어 배경색을 한꺼번에 주기

제목 블록을 쓸 때는 단계를 지켜 주세요. 본문 안의 큰 소제목은 H2, 그 아래 작은 소제목은 H3를 씁니다. 글자 크기를 키우려고 제목 블록을 쓰는 것이 아니라, 내용의 구조를 알려 주려고 쓰는 것입니다. 검색 엔진도 이 구조를 읽습니다.

열과 그룹은 처음엔 조금 어렵게 느껴집니다. 열 블록은 큰 상자를 칸으로 나눈 것이고, 각 칸 안에 다시 다른 블록을 넣는다고 이해하면 됩니다. 그룹 블록은 여러 블록을 상자 하나에 담아 함께 옮기거나 배경을 칠할 때 씁니다.

8.3블록 다루기와 단축키

블록을 한 번 클릭하면 블록 위에 작은 도구 막대가 나타납니다. 블록 다루기는 거의 모두 이 도구 막대에서 합니다.

블록을 옮길 때는 도구 막대의 위·아래 화살표를 누르거나, 점 여섯 개 모양의 손잡이를 끌어다 놓습니다. 복제나 삭제는 도구 막대 오른쪽 끝의 점 세 개(옵션) 메뉴에 있습니다. 블록의 색, 글자 크기, 여백 같은 세부 모양은 화면 오른쪽 설정 패널에서 바꿉니다.

그림 자리 IMG-8-2 | 캡처
  • 내용: 블록을 선택했을 때 나타나는 도구 막대 (이동 화살표, 끌기 손잡이, 옵션 메뉴에 번호 표시) + 오른쪽 블록 설정 패널
  • 준비 방법: 문단 블록 하나를 선택한 상태로 캡처
  • 파일명: img-8-2_블록-도구막대.png

단축키는 세 가지만 기억해도 작업이 빨라집니다. 윈도우 기준이며, 맥에서는 Ctrl 대신 Cmd를 누릅니다.

  • Ctrl + Z: 방금 한 작업 되돌리기
  • Ctrl + Shift + D: 선택한 블록 복제
  • Shift + Alt + Z: 선택한 블록 삭제 (맥은 Ctrl + Option + Z)
팁

실수로 블록을 지웠거나 엉망이 됐다면 당황하지 말고 Ctrl + Z를 몇 번 누르세요. 발행 전이라면 오른쪽 위의 리비전(이전 버전) 기능으로 저장했던 시점으로 돌아갈 수도 있습니다.

8.4패턴으로 빠르게 만들기

블록을 하나씩 쌓는 대신, 디자이너가 미리 조립해 둔 블록 묶음을 통째로 넣을 수 있습니다. 이것을 패턴이라고 합니다. 소개 영역, 서비스 안내 3칸, 연락처 영역처럼 자주 쓰는 모양이 준비되어 있습니다.

+ 버튼으로 블록 목록을 연 뒤 패턴 탭을 누르면 테마가 제공하는 패턴이 분류별로 나옵니다. 마음에 드는 패턴을 누르면 페이지에 들어가고, 그 안의 글자와 사진만 내 것으로 바꾸면 됩니다.

예를 들면회사 소개 페이지를 처음부터 만들려면 제목, 문단, 이미지, 열 블록을 하나하나 쌓고 간격까지 맞춰야 합니다. "소개" 분류의 패턴을 넣으면 이미 보기 좋게 배치된 상태에서 시작하므로, 문구를 바꾸고 사진만 교체하면 5분 안에 그럴듯한 페이지가 완성됩니다.

스스로 확인하기 — 8장을 마쳤다면

이 장의 실습으로 자기소개 페이지를 하나 만들어 보세요. 제목 블록 하나, 문단 두 개, 이미지 한 장, "연락하기" 버튼 하나를 넣으면 됩니다.

  • + 버튼과 슬래시(/) 두 가지 방법으로 블록을 넣을 수 있다.
  • 제목 블록의 H2와 H3를 구분해 쓸 수 있다.
  • 블록을 옮기고, 복제하고, 지울 수 있다.
  • 패턴을 하나 넣고 글자를 바꿔 보았다.
  • 자기소개 페이지를 만들어 미리보기로 확인했다.
